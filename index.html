H-Bridge Motor Driver — Shoot-Through Rework

Altium Designer Power Electronics MOSFET Debug Oscilloscope

Discrete optocoupler-isolated H-bridge (12–16V rail, 8.5A stall) driving the piano robot's lateral motor. First PWM integration test at 10 kHz heated the FETs to failure within seconds while bench DC testing had passed cleanly. Probed VGS on both FETs with a Tektronix scope, root-caused shoot-through to LTV816 transition time plus a 10k pull-up RC against ~15 nF shared-gate capacitance (~150 µs, longer than the 100 µs PWM period). Executed a post-fabrication bodge on the populated board — cut 4 PMOS gate traces, added 2 STM32 GPIO enable lines through 2 new optocouplers tapped into back-side through-hole pads, added NMOS pull-downs — and ran the final demo at 20 kHz PWM with no thermal issues.

ARC4 Encryption Core

SystemVerilog DE1-SoC M10K RAM

Designed a complete ARC4 encryption/decryption core using hierarchical FSMs (Init, KSA, PRGA) with ready-enable handshake protocols, interfacing custom RTL with ~209 M10K embedded memory blocks. Scaled to 104 parallel cracking cores (52 contiguous key ranges, each a pair of cores splitting even/odd) with early-termination ASCII validation, exhausting the full 224 key space in 1.56s (10.75M keys/sec) on a Cyclone V FPGA — a 94× speedup over single-core baseline.

Implemented integer-only Bresenham's circle algorithm with 8-fold symmetry via an octant-rotating counter, then constructed Reuleaux triangles from three overlapping partial circles using fixed-point √3 arithmetic (10-bit scaling). Baccarat Game Simulator

SystemVerilog DE1-SoC

Designed a Baccarat card game engine with a clean datapath/controller split — a 10-state Moore FSM drives dealing logic and third-card rules while a separate datapath handles card registers, modulo-10 scoring, and 7-segment decoding.
